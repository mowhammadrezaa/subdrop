SubDrop on macOS (read this first)

macOS may block SubDrop the first time because it was downloaded from the internet. That is normal — not a virus.

  1. Drag SubDrop.app to the Applications folder on this disk (or to Applications in your home folder).
  2. If macOS says it cannot verify SubDrop: open System Settings → Privacy & Security, scroll down, click Open Anyway for SubDrop.
  3. Open SubDrop from Applications (or right-click SubDrop → Open → Open the first time).

Short path: SubDrop → Privacy & Security → Open Anyway

Subtitles need Subliminal: pip3 install subliminal
