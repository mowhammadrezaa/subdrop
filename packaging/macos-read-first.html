Install SubDrop (read this first)

macOS often blocks Install SubDrop the first time because it was downloaded from the internet. That is normal — not a virus.

You will not see the installer window until you complete step 1–3 below.

  1. Double-click Install SubDrop once (macOS may refuse).
  2. Open System Settings → Privacy & Security, scroll down, and click Open Anyway for Install SubDrop.
  3. Double-click Install SubDrop again → click Open.
  4. In the installer window, click Install SubDrop. Then open SubDrop from Applications.

Alternative for step 2–3: right-click Install SubDrop → Open → Open.

Subtitles need Subliminal: pip3 install subliminal
