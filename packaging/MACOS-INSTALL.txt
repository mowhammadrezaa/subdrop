Install SubDrop (macOS)
=======================

macOS may say Apple “could not verify” Install SubDrop or SubDrop.
That is Gatekeeper (not a virus). SubDrop is not notarized yet.

ONE-TIME FIX (no Terminal)
--------------------------
1. Double-click  Install SubDrop  once (it may be blocked).

2. Open  System Settings  →  Privacy & Security .

3. Scroll down in Security. You should see a message about
   Install SubDrop being blocked.

4. Click  Open Anyway , then confirm.

5. Double-click  Install SubDrop  again → click  Open .

   Alternative to step 4–5: right-click  Install SubDrop  →  Open  →  Open .

6. The installer copies SubDrop, removes the “damaged app” quarantine,
   and launches the app.

EASIEST
-------
Double-click  Install SubDrop  and follow the on-screen dialog
(“Open Settings” opens Privacy & Security for you).

Subliminal (required for downloads)
-----------------------------------
  pip3 install subliminal
