SubDrop on macOS
================

1. Open READ FIRST.html on this disk (Safari).

2. Drag SubDrop.app to Applications.

3. If macOS blocks SubDrop:
   System Settings → Privacy & Security → Open Anyway (for SubDrop).

4. Open SubDrop from Applications.

   SubDrop → Privacy & Security → Open Anyway

Subliminal: pip3 install subliminal
