Install SubDrop (macOS)
=======================

macOS may say Apple “could not verify” Install SubDrop or SubDrop.
That is Gatekeeper (not a virus). SubDrop is not notarized yet.

READ THIS BEFORE INSTALL SUBDROP
--------------------------------
The installer window does NOT appear until macOS allows Install SubDrop.

Open  READ FIRST.html  on this disk (opens in Safari) for the full steps.

Short version (no Terminal):
1. Double-click  Install SubDrop  once (may be blocked).
2. System Settings  →  Privacy & Security  →  Open Anyway .
3. Double-click  Install SubDrop  again →  Open .
4. Click  Install SubDrop  in the dialog, then open SubDrop from Applications.

The installer does not auto-launch SubDrop (avoids a stuck colorful wait cursor).

Subliminal (required for downloads)
-----------------------------------
  pip3 install subliminal
