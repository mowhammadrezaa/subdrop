Install SubDrop (macOS)
=======================

EASIEST (recommended)
---------------------
1. Open this disk image.
2. Double-click  "Install SubDrop"
3. If macOS asks whether to open it, click Open.

   If macOS will not open "Install SubDrop" at all:
   Right-click "Install SubDrop" → Open → Open (one time only).
   Then double-click "Install SubDrop" again.

The installer copies SubDrop, fixes the "damaged app" quarantine issue
automatically, and launches the app. No Terminal commands.

Manual install (optional)
-------------------------
Drag SubDrop.app to Applications, then double-click Install SubDrop once
(or contact support — manual drag may show "damaged" until fixed).

Subliminal (required for downloads)
-----------------------------------
  pip3 install subliminal
